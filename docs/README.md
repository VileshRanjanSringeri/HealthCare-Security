# Healthcare Security Analytics System

## Overview
This project is a full-stack healthcare security system designed to protect sensitive patient data while providing real-time analytics and insights. It integrates authentication, access control, and anomaly detection to ensure secure and efficient data handling.

## Key Features
- 🔐 Two-Factor Authentication (2FA)
- 👥 Role-Based Access Control (RBAC)
- 📊 Interactive dashboards for data visualization
- 🚨 Anomaly detection for identifying suspicious activity
- 📁 Secure handling of healthcare datasets

## Tech Stack
- Frontend: React + Vite
- Language: TypeScript
- Data Handling: CSV, JSON
- Security: Authentication, Encryption, RBAC
